# 🎮 2048 AI 版

一个带有人工智能的 2048 游戏，可以自动玩，也可以手动挑战！

## 🚀 在线试玩

👉 https://wbgame.github.io/2048-ai-web/

## ✨ 功能特色

### 🤖 AI 自动玩模式
- 智能算法自动计算最佳移动方向
- 实时显示 AI 思考的下一步
- 可随时暂停/接管

### 🎛️ AI 配置中心
你可以调整 AI 的参数，影响它的策略：
- **思考深度**：AI 预判的步数（1-5步）
- **角落权重**：AI 对角落的偏好程度
- **空格权重**：AI 对保留空格的重视程度
- **单调性权重**：AI 对有序排列的偏好

### 🏆 排行榜
- 本地存储你的最高分
- 查看历史记录
- 分享成绩给朋友

### 🔊 音效系统
- 移动音效
- 合并音效（随数字升级）
- 游戏结束音效
- 静音开关

### ✨ 视觉效果
- 平滑滑动动画
- 合并粒子爆炸效果
- 分数飘字动画
- 动态背景色

## 🎯 游戏规则

1. 使用方向键或滑动移动方块
2. 相同数字的方块碰撞会合并
3. 每次移动后在空白处生成新方块（2 或 4）
4. 达到 2048 即获胜！
5. 无法移动时游戏结束

## 🛠️ 技术栈

- 前端：原生 HTML5 + CSS3 + JavaScript
- AI 算法：启发式搜索 + 权重评估
- 音效：Web Audio API
- 动画：CSS3 + requestAnimationFrame
